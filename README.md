\# Otomatik Kütüphane Yönetim Sistemi (OKYS)



Bu proje, Nesne Yönelimli Programlama (OOP) prensipleri kullanılarak Java dilinde geliştirilmiş bir Kütüphane Yönetim Sistemi simülasyonudur.



\## Proje Yapısı

\- `src/`: Projenin Java kaynak kodlarını içerir (`Kitap`, `KitapKopyasi`, `Kullanici`, `OduncKaydi`, `Main`).

\- `doc/`: Yazılım mimarisi ve UML diyagramlarını içerir (`okys-DESIGN.drawio`).



\## Kullanılan Teknolojiler \& Prensipler

\- \*\*Java OOP\*\*: Encapsulation (`private`), Immutability (`final`), Class-level state (`static`).

\- \*\*Koleksiyonlar\*\*: `ArrayList` yapısı kullanılmıştır.

\- \*\*Tasarım\*\*: UML Nesne ve Sınıf Diyagramları (`draw.io`).



\## Çalıştırma

`src/Main.java` dosyası çalıştırılarak örnek senaryolar (kitap ekleme, kopya oluşturma, ödünç alma ve iade süreçleri) test edilebilir.
